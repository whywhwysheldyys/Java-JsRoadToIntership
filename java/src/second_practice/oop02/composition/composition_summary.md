# Конспект: Композиция и Агрегация в Java

**Пакет проекта:** `second_practice.oop02.composition` (практический блок `oop10/composition`)

## 1. Основные понятия

* **Композиция и Агрегация** — способы построения сложных объектов из более простых классов. Они описывают отношение **«HAS-A»** (*«имеет» / «содержит в себе»*).
* **Принцип ООП:** *"Favor composition over inheritance"* (Преимущественно используйте композицию вместо наследования) — этот подход обеспечивает более слабую связанность (*loose coupling*) и гибкость архитектуры.

---

## 2. Сравнение: Композиция vs Агрегация

| Критерий | Композиция (Composition) | Агрегация (Aggregation) |
| :--- | :--- | :--- |
| **Связь** | Жесткая (сильная) | Мягкая (слабая) |
| **Время жизни (Lifecycle)** | Зависимое: вложенный объект **не может** существовать без главного. | Независимое: вложенный объект **продолжает жить**, если главный удален. |
| **Создание/Передача** | Компоненты создаются внутри или привязываются намертво. | Передаются извне (через конструктор/сеттеры). |
| **Пример** | `Computer` — `Processor` (ПК удален $\rightarrow$ процессор удален) | `University` — `Student` (университет закрыт $\rightarrow$ студент остался) |

---

## 3. Разбор практических решений

### 1. Компьютер и его комплектующие (`Processor.java`, `RAM.java`, `Computer.java`, `ComputerMain.java`)
* Продемонстрирована композиция компонентов.
* Класс `Computer` включает в себя экземпляры `Processor` и `RAM` и предоставляет метод `printSpecifications()` для консольного вывода их данных.

### 2. Автомобиль и Двигатель (`Engine.java`, `Car.java`, `CarMain.java`)
* Показы концепции делегирования вызовов (*delegation*).
* Класс `Car` принимает объект `Engine` и передает ему управление при вызове собственных методов `startCar()` и `stopCar()`.

### 3. Университет и Студенты (`Student.java`, `University.java`, `UniversityMain.java`)
* Продемонстрирована классическая агрегация.
* Объекты `Student` создаются независимо вне университета, переопределяют метод `toString()`, объединяются в массив и передаются в класс `University`.
