# Конспект: Абстрактные классы (`abstract class`) в Java

**Пакет проекта:** `second_practice.oop02.abstractclass` (практический блок `oop07/abstract_classes`)

## 1. Основные понятия

* **Абстрактный класс (`abstract class`)** — класс, предназначенный исключительно для наследования (служит шаблоном или каркасом для будущих дочерних классов).
* **Главное ограничение:** Нельзя создать экземпляр (объект) абстрактного класса с помощью оператора `new` (например, `new Shape()` вызовет ошибку компиляции).
* Абстрактный класс может содержать как **обычные методы** с реализацией, так и **абстрактные методы** без тела.

## 2. Абстрактные методы (`abstract method`)

* **Абстрактный метод** — это метод без реализации (без фигурых скобок `{}`), содержащий только сигнатуру.
* Завершается точкой с запятой:
  ```java
  public abstract void attack(GameCharacter target);
  ```
* **Обязательное правило:** Все обычные (неабстрактные) дочерние классы **обязаны переопределить** (`@Override`) и реализовать абсолютно все абстрактные методы родителя.

## 3. Поля и Конструкторы

* В отличие от интерфейсов, абстрактный класс может содержать обычные нефинальные поля с любыми модификаторами доступа (`private`, `protected` и т.д.).
* **Конструктор:** Абстрактный класс имеет конструкторы, которые вызываются из дочерних классов через `super(...)` для инициализации унаследованных полей родителя.

## 4. Разбор практических решений

### 1. Геометрические фигуры (`Shape.java`, `Circle.java`, `Rectangle.java`, `ShapeMain.java`)

* Абстрактный класс `Shape` задает шаблон с полем `color` и сигнатурой метода `calculateArea()`.
* Классы-наследники `Circle` и `Rectangle` реализуют математический расчет площади для конкретных фигур.

### 2. Расчет зарплаты сотрудников (`Employee.java`, `HourlyEmployee.java`, `SalariedEmployee.java`, `CompanyMain.java`)

* `Employee` содержит базовая данные сотрудника (`name`, `id`) и метод `calculateSalary()`.
* `HourlyEmployee` рассчитывает урон/зарплату по формуле `hourlyRate * hoursWorked`.
* `SalariedEmployee` возвращает фиксированную ежемесячную ставку `monthlySalary`.

### 3. Боевая система персонажей (`GameCharacter.java`, `Warrior.java`, `Mage.java`, `GameMain.java`)

* Базовый класс `GameCharacter` содержит реализацию получения урона (`takeDamage`) и абстрактный контракт для атаки (`attack`).
* Подклассы `Warrior` и `Mage` наносят урон объекту цели (`target.takeDamage(...)`), реализуя различные стили боя.
