# Итоговый конспект: Инкапсуляция, Геттеры, Сеттеры и метод `toString()` (`oop03.encapsulation`)

**Пакет проекта:** `second_practice.oop03.encapsulation`

---

## 1. Теоретические основы

### Инкапсуляция
**Инкапсуляция** — один из базовых принципов ООП, заключающийся в сокрытии внутренней реализации класса от прямого вмешательства извне и предоставлении контролируемого интерфейса доступа к данным.

* Поля класса объявляются с модификатором доступа `private`.
* Прямой доступ к `private`-полям из других классов запрещен.
* Изменение и чтение значений выполняется через специальный открытый интерфейс — **геттеры** и **сеттеры**.

---

### Геттеры и Сеттеры (Getters & Setters)

* **Геттер (`Getter`)**: Метод для чтения значения приватного поля.
  * Шаблон именования: `getField()` (или `isField()` для типа `boolean`).
  * Всегда возвращает значение типа соответствующего поля.

* **Сеттер (`Setter`)**: Метод для записи/изменения значения приватного поля.
  * Шаблон именования: `setField(ValueType value)`.
  * Принимает значение в качестве параметра и возвращает `void`.
  * Содержит бизнес-логику **валидации** (проверку корректности входных данных) перед сохранением значения в поле.

---

### Метод `toString()` и аннотация `@Override`

* **Назначение `toString()`**: Метод возвращает текстовое (строковое) представление объекта.
* **Поведение по умолчанию**: Если не переопределить `toString()`, метод из базового класса `Object` вернет строку вида `ИмяКласса@Хешкод` (например, `User@4554617c`), указывающую на адрес объекта в памяти.
* **Аннотация `@Override`**: Указывает компилятору, что мы переопределяем существующий метод базового класса `Object`. Защищает от ошибок в сигнатуре метода.
* При вызове `System.out.println(object)` Java **автоматически** вызывает переопределенный метод `toString()` у переданного объекта.

## 2. Разбор практических решений

### 1. Класс `User` (Валидация возраста)
* **Поля:** `private String username`, `private String email`, `private int age`.
* **Валидация:** В сеттере `setAge(int age)` проверяется условие `age <= 0 || age >= 120`. В случае некорректных данных выводится сообщение об ошибке, а значение поля не изменяется.
* **Конструктор:** Инициализирует `age` через вызов `setAge(age)` для гарантированной валидации при создании объекта.
* **Переопределение `toString()`:** Возвращает форматированную строку с данными о пользователе.

### 2. Класс `Product` (Учет и проверка диапазона)
* **Поля:** `private String name`, `private double price`, `private int quantity`.
* **Валидация:**
  * `setPrice(double price)`: запрещает отрицательную цену (`price < 0`).
  * `setQuantity(int quantity)`: запрещает количество меньше нуля (`quantity < 0`).
* **Логика:** Метод `calculateTotalPrice()` рассчитывает общую стоимость товара на складе (`price * quantity`).

### 3. Класс `Student` (Работа с массивами объектов)
* **Поля:** `private String fullname`, `private int course`, `private double gpa`.
* **Валидация:**
  * `setCourse(int course)`: курс должен быть в пределах от `1` до `6`.
  * `setGpa(double gpa)`: средний балл должен быть в пределах от `0.0` до `5.0`.
* **Практическое применение:** Создан массив `Student[]` в классе `StudentMain`, с последовательным выводом данных каждого студента в цикле `for-each` через `toString()`.
