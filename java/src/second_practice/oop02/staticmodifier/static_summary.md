# Конспект: Ключевое слово `static` в Java

**Пакет проекта:** `second_practice.oop02.staticmodifier` (практический блок `oop06/static_concept`)

## 1. Основные понятия

* **`static` (статический)** — модификатор, который указывает на то, что поле или метод принадлежит **всему классу целиком**, а не его конкретному объекту (экземпляру).
* Память под статические переменные выделяется **один раз** при загрузке класса в JVM, и все объекты класса делят её между собой.

## 2. Статические поля и методы

### Статические поля
Переменная хранит состояние, общее для всех экземпляров.
* **Пример:** Счетчик созданных объектов (`count++` в конструкторе).

### Статические методы
Вызываются без создания объекта (`ClassName.methodName()`).
* **Ограничение:** Из статического метода **нельзя** напрямую обращаться к нестатическим (`instance`) полям и методам, а также использовать `this` или `super`, так как в момент вызова статики конкретного объекта может не существовать.

## 3. Утилитарные классы

* Классы, состоящие только из статических методов и констант (например, `java.lang.Math`).
* **Лучшая практика:** Объявлять `private` конструктор (`private MathUtils() {}`), чтобы запретить случайное создание объектов этого класса через `new`.

## 4. Статический блок инициализации (`static { ... }`)

* Блок кода, который выполняется **ровно один раз** при первой загрузке класса в память (до вызова любых методов или создания объектов).
* Используется для сложной инициализации статических переменных и констант (`public static final`).

---

## 5. Разбор практических решений

### 1. Счетчик объектов (`Counter.java`, `CounterMain.java`)
* `private static int count` хранит общее количество экземпляров.
* При каждом вызове конструктора выполнялось `count++`.
* Метод `Counter.getCount()` возвращает актуальное значение с любого объекта или напрямую из класса.

### 2. Утилитарный класс (`MathUtils.java`, `MathMain.java`)
* Конструктор закрыт через `private`.
* Методы `add()`, `max()` и `calculateCircleArea()` сделаны статическими и вызываются напрямую (`MathUtils.add(...)`).

### 3. Конфигурация БД (`DatabaseConfig.java`, `ConfigMain.java`)
* Константы `DB_URL` и `PORT` объявлены как `public static final`.
* Инициализация выполнена внутри `static { ... }`.
* При первой обращении к классу сначала отработал статический блок, а затем вывелись значения.
