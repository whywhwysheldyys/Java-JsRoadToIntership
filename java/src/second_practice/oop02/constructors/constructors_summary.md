# Итоговый конспект: Классы, Объекты и Конструкторы (`oop02.constructors`)

**Пакет проекта:** `second_practice.oop02.constructors`

## 1. Теоретические основы

* **Класс vs Объект:**
  * **Класс** — это чертеж, шаблон или тип данных, описывающий состояние (поля) и поведение (методы).
  * **Объект** — конкретный экземпляр класса, созданный в памяти через оператор `new`.

* **Что такое конструктор?**
  Конструктор — специальный блок кода, который вызывается при создании объекта (`new ClassName()`) для инициализации его начального состояния (полей).

* **Правила создания конструктора:**
  1. Имя конструктора **строго совпадает** с именем класса.
  2. У конструктора **нет типа возвращаемого значения** (даже `void`).
  3. Модификатор доступа обычно `public` (но может быть и другим).

* **Конструктор по умолчанию (Default Constructor):**
  * Если в классе **не объявлено ни одного** конструктора, компилятор Java автоматически создает скрытый конструктор без параметров.
  * Если объявить **хотя бы один** собственный конструктор, дефолтный конструктор больше не создается автоматически.

* **Ключевое слово `this`:**
  * Ссылается на **текущий экземпляр** класса.
  * Используется для устранения неоднозначности, когда имена параметров конструктора/метода совпадают с именами полей класса (`this.owner = owner;`).

## 2. Перегрузка конструкторов (Constructor Overloading)

Класс может содержать несколько конструкторов с одинаковым именем, если у них **разное количество или типы параметров**. Это позволяет создавать объекты с разным набором начальных данных.

## 3. Разбор практических решений

### 1. Класс `Car` (Дефолтный и параметризованный конструкторы)
* Описан класс с закрытыми полями (`brand`, `model`, `year`).
* Конструктор без параметров заполняет поля дефолтными значениями (`"Unknown"`, `"Unknown"`, `2020`).
* Перегруженный конструктор принимает все 3 значения и инициализирует их через `this`.

### 2. Класс `Book` (Многоуровневая перегрузка)
* Продемонстрирована перегрузка из трех конструкторов под разные сценарии:
  * Только название и автор.
  * Название, автор и количество страниц.
  * Полный набор параметров (включая цену).

### 3. Класс `BankAccount` (Логика и инкапсуляция)
* Перегрузка конструкторов для создания счета без начального баланса и с ним.
* Методы `deposit` и `withdraw` включают проверки входных данных (защита от отрицательных сумм и снятия сверх баланса).
* Возврат значений через методы-геттеры (`getBalance`).
