# Конспект: Наследование (`extends`) и переопределение методов (`@Override`)

**Пакет проекта:** `second_practice.oop02.inheritance` (практический блок `oop05/inheritance`)

---

## 1. Основные понятия

* **Наследование (`extends`)** — механизм ООП, позволяющий одному классу (подклассу/дочернему классу) перенимать поля и методы другого класса (суперкласса/родительского класса). Помогает избежать дублирования кода и выстраивать иерархию объектов.
* **Суперкласс (родитель)** — класс, чью структуру и поведение наследуют.
* **Подкласс (ребенок)** — класс, который расширяет функционал родителя, добавляя собственные поля и методы или изменяя существующие.
* **Ограничение Java:** В Java поддерживается **только одиночное наследование классов** (у одного дочернего класса может быть только один прямой родительский класс).

---

## 2. Ключевое слово `super`

Ключевое слово `super` используется в дочернем классе для обращения к элементам родительского класса:

1. **`super(...)` (вызов конструктора родителя):**
   * Вызывает конструктор суперкласса.
   * **Обязательное правило:** Вызов `super(...)` должен быть на **самой первой строчке** внутри конструктора дочернего класса.
2. **`super.methodName()` (вызов метода родителя):**
   * Позволяет вызвать унаследованную реализацию метода (например, чтобы дополнить её, а не переписывать с нуля).

---

## 3. Переопределение методов (`Method Overriding`)

* Подкласс может изменить поведение унаследованного метода, создав метод с **точно такой же сигнатурой** (именем, возвращаемым типом и параметрами).
* **Аннотация `@Override`:** Явно указывает компилятору, что метод переопределяет родительский. Помогает предотвратить ошибки при написании (например, опечатки в названии или различие в параметрах).

---

## 4. Полиморфизм

Полиморфизм позволяет использовать объекты дочерних классов везде, где ожидается родительский тип.

* Переменная типа суперкласса может ссылаться на объект любого подкласса:
  ```java
  Animal cat = new Cat("Мурчик");
  Animal dog = new Dog("Бобик");
  ```
* При вызове переопределенного метода выполняется реализация именно того объекта, который был создан в памяти (`new Cat()` или `new Dog()`), а не тип переменной.

---

## 5. Разбор практических решений

### 1. Иерархия сотрудников (`Employee.java`, `Manager.java`, `EmployeeMain.java`)
* Класс `Employee` содержит базовая поля (`name`, `salary`) и метод `work()`.
* Класс `Manager` расширяет `Employee`, добавляет поле `teamSize` и переопределяет метод `work()` через `@Override`.

### 2. Полиморфизм животных (`Animal.java`, `Dog.java`, `Cat.java`, `AnimalMain.java`)
* Создан единый массив базового типа `Animal[]`, в котором хранятся разные объекты (`Cat`, `Dog`).
* В цикле `for-each` для каждого элемента вызывается метод `makeSound()`, демонстрирующий динамическое связывание и полиморфное поведение.

### 3. Транспорт и `super` (`Vehicle.java`, `Car.java`, `VehicleMain.java`)
* В конструкторе `Car` вызывается родительский конструктор `super(brand, speed)`.
* В методе `showInfo()` вызвана родительская реализация `super.showInfo()`, после чего выводится дополнительное свойство `doorsCount`.
