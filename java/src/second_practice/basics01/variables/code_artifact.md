# 📚 Java Basics: Variables, Primitives & Literals

## 1. Архитектура и Платформа
* **Write Once, Run Anywhere (WORA):** Исходный код Java компилируется не в машинный код ОС, а в байт-код (`.class`). Этот байт-код запускается на **JVM (Java Virtual Machine)** любой операционной системы.
* **Переменная:** Ячейка памяти для хранения данных. Для примитивных типов хранит само значение, для ссылочных — адрес объекта в памяти.

## 2. Соглашения об именовании (Naming Conventions)
* **`camelCase`** — для переменных и методов (например, `hoursWorked`, `calculateSalary`).
* **`PascalCase`** — для имен классов (например, `SalaryCalculator`, `UnitConverter`).
* **`UPPER_SNAKE_CASE`** — для констант (например, `MAX_VALUE`, `PI`), объявленных через ключевое слово `final`.

## 3. Примитивные типы данных (8 типов)
* **Целочисленные:**
  * `byte` (1 байт)
  * `short` (2 байта)
  * `int` (4 байта, основной по умолчанию)
  * `long` (8 байт, требует суффикс `L`)
* **С плавающей точкой:**
  * `float` (4 байта, требует суффикс `f`)
  * `double` (8 байт, основной по умолчанию)
* **Символьный:**
  * `char` (2 байта, хранит символ Unicode в одинарных кавычках `'a'`).
* **Логический:**
  * `boolean` (`true` / `false`).

## 4. Литералы
* Литералы — это «сырые» фиксированные значения, прописанные прямо в коде.
* Компилятор по умолчанию воспринимает целые числа как `int`, а дробные как `double`. 
* Принудительные суффиксы: `L` (для `long`), `f` или `F` (для `float`), `d` или `D` (для `double`).

## 5. Объявление, Инициализация и Присваивание
* **Объявление (Declaration):** создание переменной с указанием типа `int number;`.
* **Инициализация (Initialization):** присвоение начального значения при создании `int number = 10;`.
* **Присваивание (Assignment):** перезапись значения позже `number = 20;`.
* *Важно:* Локальная переменная метода должна быть обязательно инициализирована до ее первого использования, иначе компилятор выдаст ошибку.

## 6. Лучшие практики (Best Practices)
* **Промежуточные переменные (Descriptive Variables):** разбиение сложных математических формул на логические шаги делает код самодокументируемым и удобным для отладки (Debugging).
