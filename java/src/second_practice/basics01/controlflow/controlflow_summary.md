# 📚 Java Basics: Control Flow & Loops

## 1. Ветвление: `if-else` vs `switch`

### `if-else`
* Используется для сложных логических условий, диапазонов чисел и комбинированных проверок (с операторами `&&`, `||`).
* **Порядок условий важен:** Самые специфичные и строгие условия (или валидация ошибок) должны располагаться на самых первых местах цепочки.

### `switch`
* Оптимален для точечного выбора из фиксированного набора значений (коды ошибок, дни недели, месяцы).
* Поддерживает группировку значений через запятую: `case 3, 4, 5:`.
* Ветка `default` обрабатывает все не описанные ранее сценарии.

## 2. Логические операторы и Короткое замыкание (Short-Circuit Evaluation)

* **`&&` (AND):** Возвращает `true`, только если оба операнда равны `true`.
* **`||` (OR):** Возвращает `true`, если хотя бы один операнд равен `true`.
* **`!` (NOT):** Инвертирует логическое значение (`!true` -> `false`).

### Принцип работы Short-Circuiting:
* Для `&&`: Если левая часть `false`, правая часть **даже не вычисляется** (результат гарантированно `false`).
* Для `||`: Если левая часть `true`, правая часть **пропускается** (результат гарантированно `true`).

## 3. Циклы: `for`, `while`, `do-while`

### `for` (Цикл с известным числом итераций)
```java
for (int i = 1; i <= 50; i++) {
    // тело цикла
}
```
* **Заголовок:** `Инициализация счетчика; Условие продолжения; Шаг изменения`.

### `while` (Цикл с предусловием)
```java
while (condition) {
    // тело цикла
}
```
* Проверяет условие **до** выполнения тела цикла. Если условие изначально `false`, не выполнится ни разу.

### `do-while` (Цикл с постусловием)
```java
do {
    // тело цикла
} while (condition);
```
* Гарантирует **как минимум одно выполнение** тела цикла, так как проверка условия происходит в самом конце.

---

## 4. Управление итерациями: `break` и `continue`

* **`break`:** Полностью прерывает выполнение цикла и передает управление коду, следующему за циклом.
* **`continue`:** Прерывает текущую итерацию цикла и сразу переходит к следующей (к проверке условия или шагу счетчика).

## 5. Практические навыки и паттерны

* **Алгоритм FizzBuzz:** При реализации цепочек условий для кратных чисел всегда на первое место ставится проверка на совместную делимость (`i % 3 == 0 && i % 5 == 0`), иначе более общие условия перекроют ее выполнение.
