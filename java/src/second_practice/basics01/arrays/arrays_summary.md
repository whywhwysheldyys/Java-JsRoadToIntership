# Итоговый конспект: Массивы в Java (`arrays`)

**Пакет проекта:** `second_practice.basics01.arrays`

---

## 1. Теоретические основы

* **Что такое массив?**  
  Массив — это ссылка на фиксированную структуру данных в куче (heap), предназначенную для хранения последовательности элементов одного типа.
* **Ключевые особенности:**
  * **Фиксированный размер:** Задается при создании (`new`) и не может быть изменен в течение жизни объекта.
  * **Индексация:** Элементы нумеруются с `0` до `length - 1`.
  * **Значения по умолчанию:**
    * `0` или `0.0` для числовых типов (`int`, `double` и т.д.)
    * `false` для `boolean`
    * `null` для ссылочных типов (например, `String`)
* **Исключения:**  
  Обращение к несуществующему индексу (например, `-1` или `arr.length`) вызывает **`ArrayIndexOutOfBoundsException`**.

---

## 2. Основной синтаксис

### Объявление и инициализация
```java
// Выделение памяти под 5 элементов (значения по умолчанию)
int[] numbers = new int[5];

// Явная инициализация со значениями
int[] values = {12, 45, -3, 89, 23};
```

### Обход массива
* **Классический `for`:** Используется, когда нужен доступ к индексам или требуется модифицировать массив.
  ```java
  for (int i = 0; i < values.length; i++) {
      System.out.println(values[i]);
  }
  ```
* **Цикл `for-each`:** Для простого чтение всех элементов без работы с индексами.
  ```java
  for (int val : values) {
      System.out.println(val);
  }
  ```

## 3. Практические задачи и алгоритмы

### Задача 1: Поиск максимума, минимума и суммы (`MinMaxFinder.java`)
* **Алгоритм:** Инициализация `max` и `min` значением первого элемента `arr[0]`. За один проход обновляются значения экстремумов, их индексы и аккумулируется сумма.
* **Приведение типов:** Для корректного расчета среднего значения выполняется явное приведение суммы к `double`: `(double) sum / arr.length`.

### Задача 2: Статистика температур (`TemperatureAnalyzer.java`)
* **Двухпроходный алгоритм:**
  1. *Первый проход:* Подсчет полной суммы элементов массива для расчета итогового среднего значения `averageTemp`.
  2. *Второй проход:* Сравнение каждого элемента со средней температурой и вывод дней, превысивших её.
* **Форматирование:** Использование `System.out.printf` с шаблонами `%d` (целые числа) и `%.2f` (вещественные с точностью до 2 знаков).

### Задача 3: Реверс массива на месте (`ArrayReverser.java`)
* **Алгоритм двух указателей (Two Pointers):**
  * `i` (указатель с начала, `i = 0`) и `j` (указатель с конца, `j = length - 1`).
  * Цикл выполняется, пока `i < j`.
  * Обмен элементами происходит с помощью временной переменной `temp` (**Swap algorithm**):
    ```java
    for (int i = 0, j = numbers.length - 1; i < j; i++, j--) {
        int temp = numbers[i];
        numbers[i] = numbers[j];
        numbers[j] = temp;
    }
    ```
